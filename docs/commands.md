# 🗣️ Voice Commands & Grammar Reference

Remi supports over 40 browser and desktop actions in English, Hindi, and Hinglish. Commands are parsed locally with zero cloud dependencies.

---

## Navigation & Tabs

| Action | English Triggers | Hinglish / Hindi Triggers |
|---|---|---|
| **Open Site** | `open youtube`, `go to github`, `gmail` | `youtube kholo`, `github khol do`, `gmail jao` |
| **New Tab** | `new tab` | `naya tab`, `naya tab kholo` |
| **Close Tab** | `close tab` | `tab band karo`, `band karo` |
| **Next Tab** | `next tab` | `agla tab`, `agle tab kholo` |
| **Previous Tab** | `previous tab`, `last tab` | `pichla tab`, `pichle tab` |
| **Duplicate Tab** | `duplicate tab` | `tab copy karo` |
| **Back / Forward** | `go back`, `forward` | `wapas jao`, `aage jao` |
| **Refresh** | `refresh`, `reload` | `refresh karo`, `reload karo` |

## Page Interaction & DOM

| Action | English Triggers | Hinglish / Hindi Triggers |
|---|---|---|
| **Click Element** | `click <text>`, `press <button>` | `click karo <text>`, `dabao <button>` |

## Search & Quick Query

| Action | Example Command | Result |
|---|---|---|
| **YouTube Search** | `youtube lo-fi beats` | Opens `https://youtube.com/results?search_query=lo-fi+beats` |
| **Google Search** | `search nvidia rtx 4050` | Opens `https://google.com/search?q=nvidia+rtx+4050` |
| **Hindi Search** | `dhundo python tutorial` | Opens `https://google.com/search?q=python+tutorial` |
